## 一、三层风控架构（为什么不是"每 5 分钟"）

原始需求是每 5 分钟一轮。平台定时任务的**最小粒度是 1 小时**（不支持 MINUTELY），因此实际采用下面这套架构——它的**风控响应比 5 分钟轮询更快**：

| 层 | 职责 | 响应速度 | 实现 |
|----|------|----------|------|
| **L1 交易所端硬风控** | 止盈止损执行 | **秒级，7×24 不间断** | 每笔开仓同时挂 OCO 算法单，由 OKX 服务器撮合触发，不依赖本系统在线 |
| **L2 AI 决策轮** | 行情分析、持仓巡检、开平仓决策、归档 | 每小时整点 | 定时任务「每小时交易轮」 |
| **L3 报告层** | 日报 / 周报复盘 | 每日 23:50 / 每周日 23:55 | 定时任务 |

**关键点**：5 分钟轮询的价值主要在"及时止损"，而这件事已由 L1 交易所端算法单以秒级精度完成。L2 的小时级节奏反而过滤掉了 5 分钟级别的市场噪音——在加密市场中，5 分钟级的频繁决策更容易产生过度交易，与"长期稳定盈利"的目标相悖。

## 六、核心策略逻辑摘要

**多周期共振评分**（4H 权重 50% / 1H 30% / 15m 20%），范围 -100 ~ +100，由趋势排列、EMA200 位置、MACD、RSI 极值修正合成。

开仓有**两条互斥路径**（章程 v1.3）。先判路径 A，A 不通过才判路径 B，同一标的两路径不并存。**两条路径均已生效。**

| | 路径 A：趋势共振 | 路径 B：区间均值回归 |
|---|---|---|
| 状态 | ✅ 生效 | ✅ **已生效**（2026-09-01 用户批准） |
| 适用市况 | 趋势行情 | 4H 震荡（trend=range）且布林带宽 ≤3.5% |
| 触发门槛 | 七道全过：① 共振分 \|score\| ≥ **28** ② 4H/1H 趋势不冲突 ③ 量比 ≥ **0.8** ④ 避开 4H 区间 **38%~62%** 分位 ⑤ 盈亏比 ≥ **1.6:1** ⑥ \|资金费率\| ≤ 0.05% ⑦ 无同向持仓 | 四项全过：① 4H 布林 %B ≤0.10（多）/ ≥0.90（空）② 4H 区间分位 ≤25%（多）/ ≥75%（空）③ 15m RSI ≤35（多）/ ≥65（空）④ **15m 量比 ≥ 1.2**（放量止跌确认） |
| 单笔风险 | **档位基准 1.5% × 信号系数**（进攻 2.0% / 防守 0.5%，硬顶 2%） | **0.8%**（进攻档 1.0%，仍低于路径 A，因逆势承接） |
| 止损距离 | 1.5×ATR(1H)，上限 2.5×ATR(1H) | min(1.2×ATR(4H), 区间边界外 0.3%)，取更近 |
| 止盈目标 | ≥ 2R | 4H 布林中轨（均值回归目标） |
| 盈亏比要求 | ≥ 1.6:1 | ≥ 1.5:1 |
| 最长持仓 | 24h（浮盈 <0.5R 则平） | **18h** |
| 频次 | — | 每日最多 **2** 笔，同标的 12h 内不重复 |
| 时间止损 | 超 24h 且浮盈 <0.5R 平仓 | **超 12h 无条件平仓** |
> 路径 B 是**策略补全**而非门槛放宽：它的风险预算更低（0.8% vs 1.5%）、止损更近、量能要求更高（1.2 vs 0.8）、还有 18h 时间上限。
> 设立动因是 v1.0 只有趋势路径，会在震荡市结构性空转。四条红线（仅 BTC/ETH 永续、≤5x、强制止盈止损、多空自主）零改动。

**仓位规模**：ATR 风险预算法。名义敞口 = 单笔风险预算 ÷ 止损百分比，张数向下取整到 0.01。

```
单笔风险 R = 总权益 × risk_pct
  risk_pct = 档位基准（§5.3，每轮由脚本给出）× 信号强度系数（0.80 / 1.00）
  硬顶 2.0%
```

上限（同时校验取最严）：单标的 ≤ **3.0×** 权益、总敞口 ≤ **5.0×** 权益、杠杆 ≤ 5、单笔风险 ≤ **2.0%**。

**止损止盈**：一律用 mark 价触发（防插针），开仓同时挂 OCO，浮盈达 1.5R 移至保本。

**熔断**：当日 **3** 次止损 或 回撤 ≥**5%** → 停止开新仓。**月度回撤 ≥8%** → 切防守档并放弃当月目标。

### 月度目标：≥ +10%（进阶目标，年化 213.8%）

用户 2026-09-01 设定，并明确"可以开杠杆，不要限制太死"。这不是口号，有数学拆解（章程 §0.1）：

```
单笔期望 E = 胜率 × 平均盈利R − (1−胜率) × 1R
  保守：W=45% / 1.8R → E = 0.26R

月度需要笔数 N = 10% ÷ (E × risk_pct)
  risk_pct 1.0% → 38 笔/月  ← 原档位下不可达
  risk_pct 1.5% → 26 笔/月
  risk_pct 2.0% → 19 笔/月  ← 可行区间
```

**达成需要三件事同时成立**：单笔风险 1.5%~2%、月成交 15~25 笔、平均盈亏比站住 1.6:1 以上。v1.3 的放宽正是为此。

**代价**：risk_pct = 2% 时连亏 5 笔 ≈ 回撤 −9.6%，由 §5.3 降档机制兜底。

**目标进度自适应风险档位**（§5.3，每轮由脚本计算）：

| 档位 | risk_pct | 触发条件 |
|---|---|---|
| `DEFEND` 防守 | 0.5% | 月度回撤 ≥ 8% |
| `REDUCE` 降档 | 1.0% | 月度回撤 5%~8% |
| `LOCK` 锁利 | 0.8% | 月度已达标 ≥10% |
| `ATTACK` 进攻 | 2.0% | 完成度 < 时间进度×50%，且当月已过 ≥20% |
| `BASE` 基准 | 1.5% | 其余情况（默认） |

三条防滥用约束：① 进攻档**只放大仓位，绝不降低 §4 开仓门槛**（降门槛 = 让负期望信号进场）；② 设 20% 最小时间进度门槛（否则月初必然误判落后而满仓）；③ 月度回撤优先级最高，触发降档后当月不再回进攻档。

### 消息面：否决权，不是开仓信号发生器

消息面**永远不会单独触发开仓**。它只有三种作用（章程 §10.4）：

| 闸门 | 触发条件 | 效果 |
|------|----------|------|
| ① 事件闸门 | FOMC / 非农 / CPI 公布前后 2 小时 | 禁止开新仓（已有持仓靠 OCO 保护，不手动干预） |
| ② 方向否决 | A 级 + 高影响消息与技术信号方向相反 | 该标的本轮禁止开仓 |
| ③ 共振加成 | A 级消息与技术信号同向 | risk_pct 可取该档上限 |

**可信度分级**：A = 多源交叉验证 / B = 单一专业源 / C = 自媒体仅情绪参考（禁止用于决策）/ D = 传闻（脚本拒绝入库）。

**交叉验证是强制的**。2026-09-01 实测教训：同一 CME 指标，GO Markets（8/26）报加息概率 36.1%，四家中文财经（9/1）报 65.4% —— 相隔 6 天结论完全反转，转折点是 Jackson Hole。**用过期数据决策比没有数据更危险**，故宏观预期类消息超 48 小时必须重验。

数据源实测评估见 `NEWS_SOURCES.md`：东方财富检索是主力，`WebSearch` 是唯一可靠的验证手段，腾讯自选股 `data_macro` 因返回值日期乱序**不推荐**用于实时宏观。

### 自动进化：每一笔亏损都必须换来一条规则改进

```
平仓 → --prepare 列出待复盘 → 强制归因（七选一）→ --commit 落账 EVOLUTION.md
     → 同类归因累计 ≥3 次 → 自动生成提案写入 PLAYBOOK.md「待批准区」
     → 用户批准 → 写入章程，版本 +1
```

- **亏损交易未复盘 → 禁止开新仓**（章程 §7 第 4 步硬性拦截）
- 归因固定七类：`signal_quality` / `timing` / `sizing` / `stop_loss` / `take_profit` / `external_event` / `execution`
- 禁止"行情不好""运气差"这类无信息量归因 —— 脚本直接拒绝入库
- **待批准区的规则一律不生效**，AI 不得据此交易
- 单笔亏损后不改策略（防过拟合），需同类累计 ≥3 次才生成提案
